# CablePro Landing Page

A professional, conversion-focused landing page for CablePro, the leading management software for cable TV operators.

## Features
- **Modern Design**: Premium aesthetic with a trusted blue color scheme.
- **Conversion Optimized**: Multiple Call-to-Action points and benefit-focused copy.
- **Responsive**: Fully optimized for Mobile, Tablet, and Desktop.
- **Smooth Interactions**: Scroll-reveal animations and sticky navigation.

## Directory Structure
```
/landing-page/
├── index.html      # Main HTML structure
├── css/
│   └── styles.css  # Design system and styling
├── js/
│   └── main.js     # Interactions and animations
├── images/         # Logo and mockups
└── README.md
```

## Setup
Simply open `index.html` in any modern web browser to view the landing page.

## Technologies Used
- Semantic HTML5
- Custom CSS3 (Flexbox/Grid/Variables)
- JavaScript (Intersection Observer API)
- Google Fonts & Material Symbols
